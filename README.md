# Six months of AI and Data Science Mentorship Program

Welcome to the **Six Months of AI and Data Science Mentorship Program** – a complete and practical journey from fundamentals to advanced topics in data science and AI.

This repository includes well-organized notebooks, projects, and resources to help you build a strong foundation in:

-  Pandas
-  Numpy
-  Mathematics for ML
-  Statistics
-  Machine Learning

---

## 📁 Folder Structure

| Folder / File | Description |
|---------------|-------------|
| `01_pandas_tips_tricks` | Hands-on tips and tricks using Pandas |
| `04_numpy` | Deep dive into Numpy arrays and operations |
| `06_mathematics` | Mathematical concepts essential for ML |
| `07_statistics` | Statistics with real examples (Day 66, etc.) |
| `08_machine_learning` | Machine Learning projects and concepts (Day 92, etc.) |
| `data` | Raw and processed datasets used in projects |

| `outputs` | Saved outputs of different experiments |
| `best-model-selection-with-hyper-parameter-tuning.ipynb` | Kaggle-based notebook on model selection |
